     Evidence: across the whole dataset y2 spans 4.0e-08 to 3.642e-05, so the
          global-search absolute tolerance of 1E-3 is 27x larger than y2's
          largest value. y3 peaks at 0.3828, y1 at 1.0.
     Why: PIDController bounds the local error by |y|*rtol + atol, so an atol
          above the entire range of a state leaves that state effectively
          unconstrained. During the global search the integrator is free to
          return almost anything for y2, yet the loss scales each column by its
          own maximum — so y2 carries a full third of the residual while being
          the least resolved. The gradient stage is unaffected (its atol is
          1e-9); this only degrades the point PSO hands over.
